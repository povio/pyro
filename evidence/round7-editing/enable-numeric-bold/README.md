## Why the same markup can render different weights

The pinned bold page loads editing/include/reset.css, which sets `b, strong { font-weight: bold }`. An ordinary document instead gives B the UA weight `bolder`. In the weight-100 middle fixture the pinned expectation contains `<span style="font-weight:100">foo<b>bar</b>baz</span>`. In signed Chrome the selected glyphs in that literal markup compute to 400 without the reset, and 700 with the reset. Chrome's actual command splits the span around the selected run and produces 700 in both environments. In the 500-to-600 selection the legacy nested markup can instead produce 900 on the selected portion of the 600 span. The final candidate handles the effective rendered weight in either document.
