Enter in a P or DIV with a single text child resolves a caret in an ordinary-space run to the rendered split position. An interior run leaves one NBSP on each side that needs visible width. Leading and trailing spaces that were already invisible stay with their text. At a leading edge the caret lands after the original leading spaces on the new line.
