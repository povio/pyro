A font size, family or foreground-color command can split a single-purpose HTML FONT or SPAN at the selection edges. It applies the new value only to the selected portion. Wrappers carrying additional attributes or declarations keep their existing formatting path. The background-color commands can similarly replace paint within a single run. Selections crossing paint boundaries retain the surrounding background wrappers. When deciding whether the selected text can inherit a requested font size, the engine checks the CSS keyword behind the computed value. A coincident pixel measurement alone is insufficient.
