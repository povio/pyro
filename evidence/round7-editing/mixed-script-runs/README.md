# Mixed subscript and superscript selections

Source `ed70d150f13b4cbc3ea5efed084619473ff4fc93` extends mixed-run joining when plain text enters a matching script carrier. A selection spanning active semantic and CSS carriers can remove the selected alignment from both. The correction preserves the existing wrapper around an unselected suffix.

All eight frozen signed-Chrome assertions recovered. The 44 WPT pages have 33,326 assertions common to all three engines and another 26 present only in signed Chrome. Candidate and exact parent have identical membership, eight gains and zero losses. All 10,092 assertions on the ten command guard pages retained their parent status. Complete glyph vectors, including font size, and serialized markup agreed in 56. Anchor and focus each agreed in 60, with both agreeing in 56. On repeat, alignment, direction, selected text and queried flags agreed in all 64. Complete glyph vectors agreed in 48, markup in 40 and connectivity in 56. All 112 earlier opposite-script cases matched the exact parent across every recorded field. [Direct field counts](head-scores.json)

**Live DOM after undo.** After two undos, all 64 matched signed Chrome on glyphs, both selection endpoints, direction and selected text. Serialized markup agreed in 56. Pyro restores the host from serialized markup, so the connected original-node vector differed from Chrome in all 64, including on the exact parent.

**Detached references after undo.** Eight full-pair cases lost an incidental parent match on original-node text. Chrome and candidate emptied the fully selected span when removing it. Undo reattached Chrome’s original span and restored its text. Pyro reconstructed the live subtree, leaving the old span empty. The parent had preserved the old span’s text by failing to remove its alignment. The coordinator accepted this difference for publication. [Eight indexed records](head-losses.json.gz)
