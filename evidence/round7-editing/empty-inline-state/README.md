# Bold on a range containing only empty inline markup

Tested source `b069b51fb9b5f2d0f9130ea5ae065b08753ccc51`, tree `7ca409adc563a8c1d6cabc981a039974cdc61818`, executable SHA-256 `271906896c402ab96c72125cb813eef6bbd2b3881385b8a841ccf202d8c3c36a`. The integration parent `396d89078` differs from tested `bbb8a3256` only in evidence. The original inline-highlight revision3 executable rehashed to `95cd07cfc5289107a532e7050951d1ee13f7f919d9bcfbd872938dcfa2e2e6d3`. Its original build and 44-page WPT receipts supplied the parent. Direct measurements used that binary and signed Chrome 158.0.8127.37.

The command keeps the DOM range and sets pending bold for insertion when all selected children are empty eligible inline elements. The initial state comes from the neighboring visible text. A second toggle reverses the override. Typing keeps the original empty markup, using the visible range edge and reusing an adjacent legacy B when appropriate.

Independent QA matched 33,326 assertions with unchanged membership. All four targeted post-command bold-state assertions recovered with zero losses. The four target shapes cover B, I, B containing I and I containing B. Across both directions, CSS modes and one or two toggles, all 32 direct target cases matched the actual typed glyph weight and italic style, markup, caret and direction. With plain neighboring text the first toggle produces a 700-weight Q; toggling twice yields 400. The toggle itself preserves anchor/focus, creates no undo step and emits no input event in these target cases. [Target glyphs, markup and caret](target-typing.json)

Direct probes also cover adjacent bold content, a leading empty span, a BR, nonempty text, plaintext-only descendants and noneditable islands. Across 80 core cases the first command state matched in all 80 and typed glyph vectors in 72. The 40 fresh history cases matched on typed glyphs, undo markup and undo endpoints in all 40; redo endpoints matched in 20. Cases outside the empty rich-inline scope retain preexisting discrepancies. For example, selecting a locked empty B and typing can insert text inside it in the parent and candidate, while Chrome replaces the selected element. No previously matching direct field was lost.

The numeric-bold native regression test passed. All 44 partial numeric-bold records were identical on parent and candidate. The 10,092 command multitest and 13,060 static guard rows kept their original parent status.
