# Trusted beforeinput target ranges and deletion

LP now returns StaticRange snapshots during dispatch of trusted beforeinput events in editable content; input events, text controls and undo/redo have empty ranges. The original event target is retained alongside the snapshot so an ancestor that sees a retargeted event cannot read internal endpoints. A canceled beforeinput event prevents the edit. If its listeners move the selection, the default deletion follows the surviving selection and edits its current host; clearing the selection prevents the deletion. After dispatch the original event clears its range. Synthetic InputEventInit.targetRanges, complete grapheme clustering and complex editing-boundary normalization remain outside this batch.

Deletion now shares its UTF-16 character step with the range calculation. A plain image or line break between text nodes can be removed as a single editable item. A trailing placeholder break is distinguished from a break inside a line. Deletions at a boundary between adjacent lists can join their items while retaining unselected items in their original containers and removing empty list shells.
