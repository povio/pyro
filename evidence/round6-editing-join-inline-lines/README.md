# Joining styled first lines in editable HTML

LP now uses DOM Range extraction to retain formatting elements while joining the first hard line of a paragraph. Moving onto an anonymous line of inline content also preserves the inherited white-space. The path checks the editing host, visible break elements, and the far-side paragraph boundary before changing the DOM. Nested block containers and a paragraph followed by an anonymous right line remain open cases.
